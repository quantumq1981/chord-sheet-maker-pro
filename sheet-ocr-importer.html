🎼 Sheet Music Chord OCR

← Chord Sheet Maker Pro
Everything runs on this device — nothing is uploaded. The first run downloads the OCR language data (~10 MB, cached afterwards). Chord names must be printed above the top staff of each system. Detected staff systems are outlined in blue, chord search bands in amber, and accepted chords in green on each page preview.
Measure/beat numbers are estimates from horizontal position under the “Bars / system” setting — adjust it to match the printed layout and re-run. Chords that fail validation are listed per page as rejected tokens so nothing disappears silently.
